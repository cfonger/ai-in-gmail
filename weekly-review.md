## Context

Use the installed Gmail MCP server to access Gmail. Follow the classification rules in .claude/CLAUDE.md.

## Your task

Run a GTD weekly review of my email. This is the "clear the decks" ritual to make sure nothing has slipped through the cracks.

### Step 1: Inbox check

Search `in:inbox` — if anything is there, flag it. The inbox should be empty if /inbox-zero has been running. If not, process it first.

### Step 2: Action items audit

Pull all emails labeled "01 Action" and "00 Action - Cust". For each:

- Is this still actionable? Or should it be archived/closed?
- Has the situation changed since it was labeled?
- Is anything past due or at risk of being forgotten?

Flag items that have been sitting in Action for more than 7 days — they may need to be either done, delegated, or deliberately deferred.

### Step 3: Waiting-for audit

Pull all emails labeled "10 Waiting For". For each:

- Is this still outstanding?
- Has it been resolved elsewhere (check thread for replies)?
- Does it need a follow-up nudge?

### Step 4: Recent archive spot-check

Search for emails from the past 7 days that were archived. Scan for anything that might have been mis-classified or that needs to be promoted back to Action now that context has changed.

### Step 5: Weekly summary

Present a dashboard:

**Inbox**: Empty / X items remaining
**Action Items**: X total (X new this week, X older than 7 days)
**Waiting For**: X total (X need follow-up)
**Mis-classifications Found**: Any emails that need re-labeling

**Patterns & Observations**: Anything you notice — recurring senders in action, areas getting lots of email, threads that keep bouncing back, etc. Think like a chief of staff giving a weekly briefing.

**Recommendations**: Specific suggestions for the week ahead — what to prioritize, what to delegate, what to let go.

### Step 6: Clean up

After review, offer to:

- Re-classify any mis-labeled emails
- Archive stale action items
- Send follow-ups on waiting-for items
- Close out anything that's resolved

## Important rules

- Never delete emails. Only add/remove labels.
- When drafting anything, never use emdashes.
- This is a thinking exercise — be thorough but don't take actions without confirmation.
